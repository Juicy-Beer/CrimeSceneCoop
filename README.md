An unofficial cooperative multiplayer mod for **Crime Scene Cleaner**. Clean up messy crime scenes together with your friends in real-time sync.

---

## Features

* **Multiplayer Sync:** Synchronize player movements, actions, and cleaned stains across clients.
* **Host & Join:** Easily host a session or connect using multiplayer controls right from the game.
* **Lightweight Integration:** Built cleanly using Harmony patches to hook into the game logic without heavy overhead.

---

## Installation & Setup

### 1. Install MelonLoader
1. Download and install [MelonLoader](https://github.com/lavagang/melonloader) for your dedicated **OS**
2. Run the game once with MelonLoader installed to generate the required folders (including the `Mods` folder).
